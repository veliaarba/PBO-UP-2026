# AI Usage Documentation

## AI Tool Used
ChatGPT (OpenAI)

## Purpose of AI Usage
AI was used as a supporting tool during the development of the P07 project.

## Areas of Assistance
1. Explaining object-oriented programming concepts used in P07.
2. Providing guidance on code implementation and organization.
3. Helping identify and understand programming errors during debugging.
4. Explaining test results and type-checking results.
5. Providing guidance on Git commands and project version control.

## Student Responsibility
All suggestions provided by AI were reviewed and evaluated by the student. The student was responsible for implementing, understanding, and testing the project code.

## Declaration
AI was used as a learning and development assistant, not as a replacement for the student's own understanding and responsibility.
